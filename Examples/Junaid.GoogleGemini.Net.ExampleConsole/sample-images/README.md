# Sample Images Directory

Place your sample images here to test the vision capabilities of the Junaid.GoogleGemini.Net library.

## Supported Image Formats:
- JPG / JPEG
- PNG  
- GIF
- BMP
- WebP

## Example Images to Test:
- Charts and graphs (for data analysis)
- Nature photos (for creative descriptions)
- Screenshots (for technical analysis)
- Artwork (for creative interpretations)
- Documents (for OCR-like functionality)

## Usage:
1. Copy your image files to this directory
2. Run the console application
3. The vision examples will automatically detect and use your images

## Note:
If no images are found, the application will create a simple test image programmatically and continue with the vision examples.
